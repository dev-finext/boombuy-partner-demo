# BoomBuy · צד השותף

ממשק סטטי לבדיקת ה-API של השותפים. הכול נטען **ישירות מה-API החי** — אין
במאגר שום עותק קפוא של נתונים, כי הרעיון הוא לבדוק את הממשק עצמו ולא תצלום שלו.

## מה יש בו

| מסך | מה הוא מראה |
|---|---|
| **הקטלוג** | מוצרים כפי ששותף יציג אותם — וריאציות מקובצות תחת מוצר אחד עם `select` למאפיינים |
| **ה-JSON הגולמי** | התשובה המלאה של `GET /api/v1/partner/products` |
| **הזמנה** | בניית `POST /api/v1/partner/orders` ושליחה אמיתית |
| **התראת WEBHOOK** | מבנה ההודעה והכותרות שנשלחות כשפריט יוצא מהמלאי |
| **מילון השדות** | מה אומר כל שדה בשורת קטלוג |

## חיבור

ברירת המחדל ב-`assets/config.js`. אפשר לדרוס אותה מ**הגדרות חיבור** בראש הדף,
והדריסה נשמרת ב-`localStorage` של הדפדפן בלבד.

**המפתח במאגר הוא של סביבת הדמה בלבד.** זהו ריפו ציבורי, ומפתח בהיסטוריית git
נשאר שם גם אחרי מחיקה — אל תחזור על התבנית הזאת עם מפתח אמיתי.

## למה 401

הקריאה יוצאת **מהדפדפן של הצופה**, אז כתובת ה-IP שלו היא זו שנבדקת מול
`allowed_ips` של השותף. מכתובת שאינה ברשימה תתקבל 401 גם עם מפתח תקין.
