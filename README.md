# BoomBuy · צד השותף

ממשק סטטי שמראה בדיוק מה שותף חיצוני מקבל מ-BoomBuy: הקטלוג, ה-JSON הגולמי,
בניית הזמנה, והתראת ה-WEBHOOK.

## שני מצבי נתונים

| מצב | מקור | למי זה עובד |
|---|---|---|
| **נתוני דוגמה** (ברירת מחדל) | `data/sample-feed.json` בריפו | לכל אחד, בלי מפתח |
| **API חי** | `GET /api/v1/partner/products` אמיתי | רק ממחשב שה-IP שלו ברשימה המורשית של השותף |

**המפתח לא נמצא באתר.** במצב חי מזינים אותו בדפדפן, והוא נשמר ב-`localStorage`
בלבד. האתר הזה ציבורי — כל דבר שיישמר בקוד שלו הופך ציבורי גם הוא.

## למה 401 במצב חי

הקריאה יוצאת **מהדפדפן של הצופה**, אז כתובת ה-IP שלו היא זו שנבדקת מול
`allowed_ips` של השותף. מכתובת אחרת תתקבל 401 גם עם מפתח תקין.

## הרצה מקומית

```
python -m http.server 8080
```
ואז `http://localhost:8080`. אין שלב בנייה — HTML, CSS ו-JS בלבד.

## רענון נתוני הדוגמה

`data/sample-feed.json` הוא פלט אמיתי של בניית הפיד, עם כתובות התמונות מופנות
ל-`https://boomclub.org.il`. להחלפה — שמרו תשובת API מלאה באותו מבנה.
